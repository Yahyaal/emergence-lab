# E-22 pre-registration: wanderer encounters (written before running)

**Question:** gliders can fuse into a double glider (E-20). Do wanderers (E-17/E-18) fuse,
annihilate, or multiply when they meet?

**Design:** rule `LENIA/R13/T10/m0.243/s0.0224/b1,0.5,0.5`. Wanderer pattern = the single
wanderer of E-18a universe #81 at t = 2000, cut out. Two copies are placed on a 160x160 torus:
copy B transformed by one of the 8 exact symmetries (rotations by 90 degrees, mirror),
separated by d in {20, 25, 30, 35, 40} cells along a random direction, B advanced 0..40 steps
(phase). 200 trials (seeded, master seed 22), 3000 steps each.

**Outcome (end state, observed with the full observatory `lab.study_universe`, so a mover must
move in its own world, J-025):** number of self-propelled structures and the masses of all
persistent objects. Categories: both destroyed / one wanderer / two wanderers / a new object
(persistent object of mass outside 90-145, e.g. ~230 = fused) / more than two movers (birth).
Any new object or birth is inspected by eye and isolated for 1000 steps. Descriptive.
