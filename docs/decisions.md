| D-020 | Cumulative innovation is tested by knockout on forked clones, against matched control deletions of old structure. Verdicts use both set and count readings; the count reading is calibrated against a **placebo** distribution (control-as-target) and judged at population level by P(real > placebo) | A causal claim needs an intervention. In sensitive systems any deletion changes the future, so the right null is a placebo deletion, not zero | Correlation-preserving space-time surrogates (R-3), which break or copy persistence; correlational "type B follows type A" statistics | accepted |
| D-021 | Claims about initial conditions or environments must hold the amount of matter fixed (density-matched controls) | E-09's patch effect vanished at matched density (E-10) | Comparing conditions with different total matter | accepted |
| D-022 | Continuous physics gets its own label rules: a 2-level value tolerance for activity and local periodicity; a near-fixed point is `frozen`; `complex` requires a self-propelled structure; runs with no mover and free activity < 0.002 are *quasi-static*, labelled `active` but settled (not ranked or bred from); `aperiodic_activity` uses free activity and `vocabulary` counts non-still persistent objects. Discrete rules are untouched | Static Lenia blob fields were labelled complex (27 of 60 random rules, all without a mover) and rewarded by the objectives; their activity is real slow edge relaxation, not rounding (J-012, C-01) | Counting persistent objects (they are instances, mostly static blobs); calling quasi-static fields `frozen` (they really change); a new class (dashboard and analysis churn for no gain); a large value tolerance (would erase slow movers) | accepted; 0.002 cut-off set from 60 rules (1.6× margin) |
| D-023 | The `smooth` start condition is Gaussian-blurred white noise (width ℓ, default 6) with nothing planted, matched to the soup by **total mass** (sum of cell values = 0.5 × density × cells), not by occupied-cell count. Discrete physics: top `density` fraction occupied (for 0/1 states mass and count coincide) | D-021 asks for matched matter; in continuous physics the dynamics are driven by mass, and a smooth field has many more weakly-filled cells than the soup (≈ 75% vs 35% of cells non-zero at density 0.35), so an occupied-cell match would leave the amount of matter set by the value mapping, not by the design | Matching occupied cells; matching mean value only up to rounding (3% short at density 0.15 before correction) | accepted |
| D-024 | The conditions study skips the exact-shape probes (innovation, knockout) for continuous physics and reports `innovating` as not applicable, as `discovery._probe` does | Continuous creatures never repeat exactly; the probes would report meaningless zeros that look like negative findings | Running them anyway; a tolerant innovation probe (not built or validated yet) | accepted |
| D-025 | For continuous physics, the start condition is part of the experiment: every Lenia/Flow-Lenia result states it, and claims about a rule's capacity to produce structure need more than the soup start. Glider studies use smooth starts; world size is reported because it changes outcomes | E-14: smooth starts produce gliders in 13–18% of worlds where soups with the same mass produce 0%; E-15: in 9× larger worlds a growing blob field wins 23/30 times | Treating the soup as a neutral default (it made E-12 report zero gliders in rules that can make them) | accepted |
| D-026 | A physics may declare `dtype = np.float32`; Flow-Lenia (`physics/flow_lenia.py`) stores its state as float32 in physical units, computed in float64 per step. The engine, `state_hash` (dtype-tagged), storage (float32 blobs, dtype read from the blob size), the damage probe and the observer's frame measures use the physics' uint8 `view` (A on [0, 2]) for display and frame measures only; the continuous structure census and exact recurrence use the true float state, with thresholds converted so they mean the same physical value as for uint8 Lenia (0.102, tolerance 2/255). uint8 physics are untouched (view = state) and bit-identical | A uint8 version with exact largest-remainder rounding conserved mass exactly but had **quantization friction**: flows under about half a level per step were rounded away, so pure diffusion of the paper's patch froze after < 50 steps (rms radius 16.6) while float kept spreading (22.2 at step 400). Experiments on it would be untrustworthy (J-016) | uint8 with exact-conserving rounding (friction; was implemented, then dropped); a hidden float state inside the physics (impossible: `step` is a pure function of the stored state); float64 states (twice the memory, no measured need) | accepted; float32 mass drift: worst 1.5e-8 relative within 1000 steps (rounding, not systematic) |
| D-027 | Continuous mover detector: an object that keeps its mass alone but has not travelled 5 cells after 100 steps keeps running up to 300 steps (`SLOW_STEPS`, mass and object count checked every 25 steps, net displacement summed). The in-world straightness rule stays at 0.5 | E-25 (pre-registered, 3,789 replayed worlds): +3 wanderer worlds (96 → 99 of 160), every extra detection confirmed by 1000 steps alone, no new false positive in any pool; the old 100-step verdict is computed first and kept, so detections only grow | Relaxing straightness to 0.25 or 0 (no extra true detections, one false positive: a crooked fragment, E-12 #2059); a longer fixed isolation for every object (slower, and no evidence it is needed for fast movers) | accepted |
| D-028 | Birth detector (`observatory/births.py`) for both physics families: an object is copied alone into the physics' vacuum and run (continuous 4000 steps, discrete 192). Copies = same shape (discrete) or mass within 2× of the parent (continuous). Generation 1: late copies ≥ 4 (discrete 3), **≥ 2× the early maximum**, holding ≥ 75% of the matter, and vacuum alone makes none. A *reproducer* also passes generation 2 (one copy alone, still matched to the original parent). Discrete scrambled patches that reproduce themselves → rule-level duplication. Gray-Scott (`physics/gray_scott.py`, two-channel float32 state) added as a known continuous reproducer | The exact-shape replication probe cannot see continuous creatures and only tests placed clones; nothing could have confirmed a Lenia birth. Two generations separate reproduction from one-off splitting (Gray-Scott worms). The doubling rule and fixed reference were added **after E-27** (J-032), where Lenia blobs bursting into world-filling labyrinths passed the first version's "late > early" rule and copy mass drifted 377 → 278 → 169 across generations; all earlier controls keep their verdicts, the labyrinth is now a deceptive control, and E-28 tests the fix on held-out worlds | Extending the exact-shape probe (cannot match continuous objects); a common-product null for continuous physics (would reject Gray-Scott, where any lump becomes a dividing spot: reported as `attractor` instead); counting in-world splits only (a split is not a copy) | accepted; revised after E-27 |
| D-029 | Heredity is tested by **transplant** (`observatory/heredity.py`): up to 16 parents of the most common mass class are each copied alone into the physics' vacuum and run 1500 steps; offspring = objects within 2× of the parent's mass; heredity = correlation of parent trait (measured in its own world) with mean offspring trait across ≥ 6 families, r ≥ 0.5 and parent-permutation p < 0.01; parents spread < 0.05 → "no variation". Controls on `GrayScottTracer` (Gray-Scott spots with a trait channel that never affects the chemistry: carried / redrawn / position). Track D physics `FlowLeniaPL`: Flow-Lenia whose kernel weights h_i are stored per cell as A·h_i and moved by the same reintegration step (mass-weighted mixing), optional uniform food layer below the object threshold | An in-world parent-offspring regression is fooled by common environment: with a trait set by position, nearest neighbours correlate (r > 0.5 in the probe world) without any inheritance; moving offspring to a common place removes that, as cross-fostering does. Mass-weighted storage makes parameter transport exact and conserved, and with uniform weights FlowLeniaPL is FlowLenia (max difference ~1e-6 after 300 steps) | In-world lineage tracking with a nearest-neighbour null (a parent is also the nearest object, so position-set traits pass); stochastic per-cell parameter sampling (adds unseeded-looking noise to a pure step function; our mixing rule has not been checked against the paper's, so FlowLeniaPL results are not directly comparable with Plantec et al.); a new heredity measure without controls | accepted |
| D-030 | The birth detector's background null also runs a **perturbed vacuum** (float states: each vacuum value × (1 + N(0, 0.02)) + N(0, 1e-4), clipped at 0); copies there → "background". The heredity test returns "unstable vacuum" when the perturbed vacuum alone makes objects of the parents' mass class within its run | E-30 (J-035): in 17 of 100 fed FlowLeniaPL worlds the detector reported reproducers, but a perfectly uniform food layer is an *unstable* fixed point: any disturbance (a parent, or noise) makes it condense into dozens of parent-sized droplets, with a copy series that doubles like real division. The exact-vacuum null cannot see this. A no-spontaneous-generation rule: copies must not arise from a slightly disturbed vacuum. Additive 1e-4 noise alone missed 2 of 17 rules; 2% relative noise caught all, and leaves Gray-Scott's vacuum empty | Additive noise only (missed slow-condensing rules); a spatial "copies grow next to copies" rule (condensation can also spread as a front from the parent); dropping fed worlds altogether (a fed world is the only way a mass-conserving creature can multiply) | accepted; post hoc, after E-30 |
| D-031 | Multi-channel Lenia (`physics/multi_lenia.py`, `MultiLenia`): C ≤ 4 float32 channels; each kernel reads one channel and writes to one; a channel's growth is the h-weighted **mean** of its kernels' growth functions, so it stays in [−1, 1] as in Lenia; objects are found on the largest channel value (`view`). One channel with one kernel equals float Lenia. Like Gray-Scott it is used through scripts and the birth detector only (the engine assumes 2D states) | E-29 left single-channel Lenia without a reproducer in 3000 rules; Chan (2020) reports self-replication only with several channels and kernels, so the single channel is the obvious next variable. The weighted mean keeps every rule's growth bounded and makes the one-channel case exactly Lenia, which gives the new physics a positive control (the Orbium glider glides at 0.54 cells/step, probe section 11) | Chan's unnormalized sum of h·G (growth can exceed 1/T per step with many kernels; harder to compare with E-29); uint8 channels (quantization friction, D-026); objects on the channel sum (a creature living in one channel would be diluted below the object threshold when other channels are empty) | accepted |
| D-040 | Program soups (Track D route 5): BFF (Agüera y Arcas et al. 2024) in `emergence/programs/bff.py`, C interpreter via ctypes checked against a pure-Python reference; modes `bff`, `noexec` (negative), `copyall` (deceptive). Replicator detector `observatory/replicators.py`: 8 copies of a candidate among 1024 random programs, 96 epochs without mutation; copies = ≥ 90% identical bytes; generation 1 passes if the late count is ≥ 64 and ≥ 4× the start; generation 2 tests one copy, still matched to the original; random programs tested the same way, and if they multiply → "rule-level duplication". The soup's 4 most common exact programs are scanned | The birth detector (D-028) works on spatial objects; programs have no space, so the same logic (intervention on copies, two generations, a rule-level null) is applied to a well-mixed soup. | D-041 | Heredity for program replicators (`observatory/program_heredity.py`): single-byte mutants of a replicator are each seeded as 8 copies among 1024 random programs (96 epochs, no mutation); among the family (≥ 90% identical to the parent), the share carrying the mutant byte (f_mut) is compared with the share carrying that byte when the unmutated parent is seeded (f_base). Inherited: viable (family ≥ 64), f_mut ≥ 0.5, f_base ≤ 0.1. "heredity" if ≥ 6 viable mutants, ≥ half inherited and a one-sided sign test of f_mut > f_base at p < 0.01. Applied only to programs already judged "replicator" (D-040) | Programs have no space, so the transplant design of D-029 becomes "seed the mutant alone in a fresh random soup": offspring can only carry the mutation by descent. f_base makes the same measurement without the mutation, so bytes that appear at that position anyway (copying errors, convergence) are not counted; only viable mutants are scored, in both arms. Controls: hand-written replicator (heredity, 12/12), noexec and copyall (no variation), a random program (no variation) | Reusing D-029's trait correlation (programs have no continuous trait); counting mutants in an evolving soup (common descent and convergent mutation are confounded); re-running the replicator test inside the heredity test (the detector misses the hand-written replicator in ~1 of 10 growth runs through early extinction, which would make the positive control flaky) | accepted |
| D-042 | Selection among program replicator variants (`observatory/program_selection.py`): a parent and a one-byte variant, 8 copies each among 1024 random programs, 96 epochs, 8 replicate soups; s = ln((n_variant + 1)/(n_parent + 1)) per replicate; a replicate is informative if the family reaches 16. "variant/parent favoured" if all informative replicates (≥ 4) share the sign and mean \|s\| > ln 2; "undecided" with < 4 informative | Head-to-head contests from equal starts make neutral drift symmetric (each sign ½ per replicate), so a consistent sign over ≥ 4 replicates plus a 2× effect is a simple, assumption-light criterion; extinction of both lines (common for the hand-written replicator) is excluded rather than scored as a tie. Controls: neutral tail variant → no difference; non-copying variant → parent favoured; copyall → undecided | Growth rate of each variant alone (misses interference between variants, which is what selection acts on); a t-test on s (s is bimodal: contests are winner-take-all); longer contests (more takeovers, but replicators also overwrite the marker byte of their rivals) | accepted |
| D-043 | Contests between unrelated program replicators (`program_selection.compete_families`): a and b (< 90% identical) seeded 8 copies each among 1024 random programs, 96 epochs; family = programs ≥ 90% identical to the replicator **or any listed alternative form** of its species (e.g. the byte-reverse of a mirror replicator); 16 replicate races (64 in E-45); "favoured" if ≥ 8 informative races, two-sided sign test p < 0.01 and mean \|s\| > ln 2 | Unrelated replicators share almost no bytes, so a marker byte (D-042) cannot be used; family identity is. A sign test over 16 races replaces D-042's "all races the same sign", which a single drift-driven loss would break. Alternative forms were added after E-44 showed a species with two forms (J-044); E-46 found that every emergent replicator has two (its reverse), so **every competitor must be counted with its reverse** (J-046). Controls: hand-written replicator vs the same copier with a redrawn inert tail (neutral), the same with a broken loop (a favoured), copyall (undecided). Known weakness: 2 of 46 null pair runs got a favoured verdict (E-44, E-45), above the nominal ~1% | A t-test on s (bimodal, winner-take-all); growth of each replicator alone (misses interference); family by edit distance (slower, no controls yet) | accepted |
| D-044 | Growth-rate fitness assay for program replicators (`observatory/program_fitness.py`): r = slope of ln(copies) from 16 copies among 4096 background programs, no mutation, until copies reach N/4 (≤ 40 rounds), 24 replicates, compared by Mann–Whitney; backgrounds "random" (random bytes) and "halting" (unmatched `]` + inert bytes: background never runs, so r = ln(1 + p/2)); calibrated on `trapped(k)`, the hand-written replicator that copies with known probability ≈ 2^-k (J-050) | Races (D-042, D-043) read end counts after drift from 8 copies each and only see large effects (E-43, E-49). | D-045 | A BFF state transition is counted only if HOE ≥ 1.0 holds at **3 consecutive checkpoints** (750 rounds) **and** the replicator detector finds a replicator after it; a single-checkpoint crossing is reported separately as a "spike". | D-048 | Parasite detector for program soups (`observatory/program_parasites.py`): a program that does not copy itself (`alone_test`: the replicator test repeated 10 times, generation 1 never grows) is a **parasite** if partners drawn from its own soup make copies of it (like it, ≥ 90%, either orientation) in ≥ 2% of pairings (both orders, 256 partners), more than byte-scrambled versions of it (one-sided Fisher p < 0.01, 4 scrambles), **and** most of its copies are templated: c·q / (c·q + n/2·b) ≥ 0.5, with b the rate at which pairs without it make it de novo.
